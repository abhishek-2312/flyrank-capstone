# FlyRank AI Capstone Project

## 🚀 Project Overview
This repository contains the foundational architecture for the FlyRank AI frontend engineering internship capstone project. 

---

## 🛠️ Technical Stack & Frameworks
- **Core Framework:** Next.js (App Router) / React
- **Language:** TypeScript
- **Styling Engine:** Tailwind CSS
- **Runtime Environment:** Node.js (LTS)
- **Package Manager:** npm

---

## 📐 Development Rules & Coding Conventions

### 1. Architectural Patterns
- Develop modular, highly reusable functional UI components.
- Maintain a clean separation between UI presentational elements and data/logic layers.

### 2. Styling & Responsiveness
- Enforce strict mobile-first layouts using native Tailwind CSS responsive design utilities (`sm:`, `md:`, `lg:`).
- Guarantee zero unexpected layout shifts or horizontal overflows across modern viewports.

### 3. Git Workflow
- All modifications to this repository must follow strict **Conventional Commits** format specifications.
